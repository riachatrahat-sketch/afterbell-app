# Afterbell Academy app (Flutter, Android)

Screens: Home, Explore (search and filters), Class, Teacher, Log in / Join, Account (learners, stars, badges,
favorites), Live classroom (reactions, raise hand, stars, quiz, brain break, anonymous feedback, teacher tools)
and My teaching (teacher's own numbers).

## First-time setup

This folder holds the app code (`lib/`, `pubspec.yaml`). The Android project files are generated by Flutter:

    cd afterbell_app
    flutter create --platforms=android --org com.afterbellacademy --project-name afterbell_app .
    flutter pub get

Then open `android/app/src/main/AndroidManifest.xml` and add these lines inside `<manifest>`, above `<application`:

    <uses-permission android:name="android.permission.INTERNET"/>
    <queries>
        <intent><action android:name="android.intent.action.VIEW"/><data android:scheme="https"/></intent>
        <intent><action android:name="android.intent.action.SENDTO"/><data android:scheme="mailto"/></intent>
    </queries>

In the same file set the app name: `android:label="Afterbell Academy"`.

If `flutter create` replaced `lib/main.dart` or `test/widget_test.dart`, copy them back from the zip.

## Run

    flutter run --dart-define=API_BASE=https://YOUR-PROJECT.vercel.app

`API_BASE` is the address of the Next.js backend, without `/api` at the end.

## Build for testing or the Play Store

    flutter build apk --release --dart-define=API_BASE=https://YOUR-PROJECT.vercel.app
    flutter build appbundle --release --dart-define=API_BASE=https://YOUR-PROJECT.vercel.app

The APK is at `build/app/outputs/flutter-apk/app-release.apk`. The Play Store needs the app bundle and a signing key:
https://docs.flutter.dev/deployment/android

## Notes

- The video part of a class opens outside the app (browser, Jitsi Meet, Google Meet or Zoom). Reactions, stars,
  quiz and feedback stay in the app.
- The sign-in token is kept in the phone's app storage (shared_preferences).
- Payments are not in the app. "See times" opens the class enroll link, or an email to the academy.
